# 🎹 Piano Fall：下落式钢琴练习

像音乐游戏一样的钢琴练习网页：音符沿着每个琴键的轨道落下，落到判定线时按下对应的键。
用 USB 连接电子琴后，网页能直接读取你按的键，判断按得对不对。

## 功能

- **导入任意 MIDI**（.mid）：点「导入 MIDI」或者把文件拖进窗口。导入的曲子保存在浏览器里，下次打开还在。
- **三种模式**
  - **演示**：自动演奏，先听一遍、看一遍
  - **等待**：音符落到线上就停下，按对了才继续（最适合学新曲）
  - **跟弹**：不等人，按节奏判 Perfect / Good / Miss
- **左手 / 右手 / 双手**分开练，另一只手可以作为伴奏自动播放
- **速度** 10%–150%，**A-B 循环**反复练难的段落
- 音符上标注音名（C D E）或唱名（do re mi），下一个要按的键在琴键上高亮
- 节拍器、小节线；成绩按曲子记录最佳准确率
- **37 键适配**（工具栏「37键」）：给 PSS-A50 这类小键盘用
  1. 先整体移调，让尽量多的音落进音域（默认只按八度移，保持原调）
  2. 还超出的段落（一只手的一个小节）整段按八度挪进来；整段跨度超过 3 个八度、怎么都挪不进来的，就整段删掉
  3. 音域在 ⚙ 设置里选，或者点「在琴上按最左边的键来设定」直接从琴上读
- **简化**（工具栏「简化」）：同一只手的和弦只保留 1–3 个音（右手留高音、左手留低音），每个起音点都保留，不降低密度
- **对比**（工具栏「对比」）：键盘放宽到原曲音域，用虚线框显示修改前的位置——黄色是挪了八度，红色是删掉，紫色是简化去掉；挪过的音会标 ↑1 / ↓1。⚙ 设置里的「修改记录」逐条列出每个小节改了什么，点一下就跳过去
- 没接琴时可以用电脑键盘（`A W S E D F T G Y H U J K`，`Z`/`X` 换八度）或者直接点屏幕上的琴键

## 连接电子琴

1. 用 USB 线（琴上的 "USB to Host" 口）或 USB-MIDI 转接线把琴接到电脑。
2. 用 **Chrome 或 Edge** 打开网页（Safari 不支持 Web MIDI），允许 MIDI 权限。
3. 右上角显示琴的名字就说明连上了。没显示的话，插好线后点一下那个标签刷新。

## 关于 Rush E

Rush E 是有版权的作品，这里没有内置它的谱子。你可以在 MuseScore 之类的网站找到 Rush E 的 MIDI（或者下载乐谱后导出成 MIDI），再导入进来。

建议的练法：
1. 先用「演示」听一遍，熟悉旋律。
2. 「等待」模式 + 右手 + 30% 速度，一段一段地用 A-B 循环练。
3. 右手熟了练左手，再双手，然后慢慢把速度往上加。
4. 曲库里的「热身 · 快速连打 + 和弦」可以先练同音快速连打。

MIDI 里每个轨道分给哪只手可以在 ⚙ 设置里改。只有一个轨道的 MIDI 可以选「按音高分」。

## 把常练的曲子放进仓库

把 `.mid` 文件放到 `songs/` 文件夹，然后在 `songs/index.json` 里登记：

```json
[
  { "file": "rush-e.mid", "title": "Rush E" }
]
```

这样任何设备打开网页都能直接选。注意 GitHub Pages 上的文件是公开的，有版权的 MIDI 更适合用「导入」，只存在自己的浏览器里。

## 部署到 GitHub Pages

纯静态网页，不需要构建：

1. 把代码推到 GitHub。
2. 在仓库的 **Settings → Pages** 里，Source 选 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
3. 等一两分钟，打开 `https://<用户名>.github.io/<仓库名>/`。

## 本地运行

```bash
python -m http.server 8765
```

然后打开 http://localhost:8765 。直接双击 `index.html` 也能用，不过 `songs/` 曲库要通过服务器才能加载。
